MEU APP MANHWA — GERADOR DE APK

Este pacote contém o projeto web e uma configuração do GitHub Actions
para gerar automaticamente um APK Android em um servidor Linux.

Arquivos principais:
- www/           aplicativo
- package.json   dependências Capacitor
- capacitor.config.json
- .github/workflows/build-apk.yml

O APK gerado pelo workflow será:
app-debug.apk
